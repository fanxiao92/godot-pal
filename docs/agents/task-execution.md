# 单任务执行与有界纠正

单票实施、失败定位或 review repair 时读取。本页是纠正政策单源；跨票选择、集成与权限交接见[多票协调](large-task-handoffs.md)，异常原件与硬停止分类见[诊断规则](test-diagnostics.md)。本文不授予提交、引擎执行、委派或远端写权限。

## 一次只做一件完整的事

以职责单一、可独立验收的行为变更为单位。开工前记录目标、排除项、独立验收预期及出处、repo/branch/HEAD/已有改动、唯一 writer、影响集、验证层与命令权限。

完整影响集包含生产者、消费者、注册/序列化、测试及正式进程测试、活跃样例和必要文档。文件数是风险信号，不是硬上限：超过10个文件时说明这些文件为什么属于同一行为、有哪些可独立交付部分、拆分后是否仍有合法可验收的中间状态。两轴评审核对聚焦与完整性，不为凑数量引入临时兼容、遗漏调用方或合并无关测试。显式批准的路径/权限限制仍是硬边界。

规格已定位到行级锚点的票，由协调者在任务简报或票评论提供锚点包：base 提交、逐文件行级影响锚点（生产者/消费者/测试/文档）、每片的 RED 声明（测试身份与字面诊断、被迁移旧断言）、逐条验证命令与期望退出码、禁改边界。实现按包执行即可用低推理档；遇未声明调用方、行为歧义或命令结果与预期不符，立即停止回报，不即兴补规格。简报同时预授权低风险决策类（既定环境配置、等价 fixture 构造）；预授权外的新决策照常停止升级。锚点包不替代独立审查与门禁，也不约束审查轴重新探索。

## 正常实施与纠正

事前声明并精确命中的 RED→实现→GREEN 属于正常计划，不消耗纠正额度。指定失败必须命中实际测试身份和独立字面诊断；编译错误、崩溃、超时、零匹配或其它失败不算预期 RED。原声明与命令必须在执行前留证，不能事后重标。同一诊断批次的相关断言可共享一片：一片内多个失败逐条预声明，RED 逐条命中即为有效，不为凑最小片数拆散同批断言。

同一已定位问题至多三轮实质修复尝试，实施内与独立审查修复共享；不同根因独立计数，不共用整票/功能预算。问题身份是被违反契约及已定位根因：稳定 `problemId` 关联共同原始证据身份与规范定位锚点，测试名、错误文本、review轴、会话、进程或attempt改变都不重置。同批实际修复多个问题，分别登记；两轴指出同一finding只记一次实际修复。同一证据改名不得获得新额度，后续新证据属于同根因时复用原ID。根因语义由证据诊断与独立审查核对；不能安全判断是否同一问题时请求决定，不猜测新ID。

初始失败、只读诊断不算修复轮。登记并开始实质修复及验证才是一轮；等待实施的登记跨恢复保留，不能再重复申请同一轮。第三轮允许执行与验证，成功可交付；若仍为同一问题失败，保全三轮原因、改变、源码身份、验证原件与剩余风险，总结并结束本次执行。第三轮解决A却出现真正新问题B时，按证据分别归因，不能盲按最后计数宣判A失败。归因未完成时保持禁止写入/重验。

旧账与原件原样保留并按实际证据归因，不清零、不把旧总数复制扣到所有新问题，也不静默豁免。遗留映射不明时停止请求决定；未开始条目须有原件及源码未变证明才能迁移为未消耗轮次。显式旧计划模式的零自主授权不扩大；旧 `extra-corrections` 不可绕过同问题三轮上限。

先保存原命令、数字退出、源码身份、原始输出及本轮报告；只读定位后，在写入/必要重验前记录：

1. 上一轮为什么失败：具体调用链、诊断及原件位置。
2. 本轮实质改变什么、为什么能解决；没有修正或新条件变化，不重复原操作。
3. 已批准行为、独立预期、路径/权限和时限是否不变；涉及的每个稳定问题ID、原始证据锚点、已用/剩余轮次及上一轮结果是什么。

三项成立且有余额，才可自主修复本任务内的编译/analyzer、fixture构造或明确违约实现。不能改预期迎合结果、降低验证强度、压制诊断或顺带修无关问题。只重验受影响或尚未成立的必要检查；未受影响的历史通过保留原范围/版本，不拼成一次全集通过。

## 停止与交付

崩溃、中止、超时、未知退出/输出不完整、未知写入/副作用、provider错误/预算耗尽立即保全停止；纠正余额不覆盖这些情况。规格冲突、新业务/架构/权限决定、原因/问题身份未定位、遗留账目不能安全归因或同问题三轮失败也停止，给出具体阻塞与解除条件。已停止的旧执行不能靠新会话自行恢复。

交付说明结果、候选身份、行为/契约差异、实际验证、未运行或未闭合项，以及需要决定的问题，附原件入口。叶子队列耗尽不是父规格完成；父规格应在当前候选上核对覆盖、已有集成证据与剩余缺口。只读审查不能替代缺失的运行层，也不自动批准、发布或关闭票。
