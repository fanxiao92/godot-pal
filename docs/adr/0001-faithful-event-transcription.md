# 原版事件采用忠实低层转写

原版脚本的可变入口、共享片段和 trigger/auto 差异，使恢复结构化控制流增加了转换与验证成本。已确认采用一条原始指令对应一条可读 JSON 命令的忠实转写，使用具名动作、标签与跳转，未知操作先无损保留；不在原版转换阶段恢复 `if`、循环或对话树。结构化指令留给后续手写新内容，具体格式与支持范围以 [事件契约](../design/events-schema.md) 为准。

这取代了早期“优先恢复结构化控制流、特殊情况才用 goto”的方案。代价是原版产物更接近反汇编，但可追溯原始地址、逐条核对并进行字节往返验证；运行时语义仍需另行测试，字节一致不能替代行为一致。
